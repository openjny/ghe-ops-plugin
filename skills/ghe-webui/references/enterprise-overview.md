# Enterprise Overview

> パス: `/enterprises/{enterprise}`

## 概要

Enterprise のトップページ。README の表示・編集と、外部リソースへのリンク集を提供する。

## トップナビゲーション

Enterprise のすべてのページで共通のトップナビゲーション。

| 項目 | パス | 備考 |

Enterprise メンバー全員に向けた README を作成・表示するエリア。
