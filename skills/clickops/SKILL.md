# ClickOps — ブラウザ経由の Web UI 操作

Web UI をブラウザツールで操作し、画面上の情報を読み取る。
**読み取り専用**。設定変更・削除・作成などの破壊的操作は行わない。

> 特定サービスの **URL パターン・ナビゲーション構造**はドメイン別スキル（例: `ghe-webui`）を参照すること。
> 本スキルはブラウザツールの使い方と操作手順に集中する。

## 前提条件

- 認証が必要なサイトの場合、ユーザーがブラウザでログイン済みであること
- ブラウザ操作ツールが利用可能であること

## 安全ガイドライン

> **重要**: このスキルは読み取り専用操作のみを行う。

- **禁止操作**: ボタンのクリックによる設定変更、フォーム送信、削除操作、権限変更
- **許可操作**: ページ遷移（リンククリック・URL 直接指定）、情報の読み取り、スクリーンショット取得、検索・フィルタリング
- タブ切り替え、ドロップダウンの展開など「表示を切り替えるだけ」の操作は許可
- 判断に迷う操作がある場合は、実行前にユーザーに確認すること

## ブラウザ操作ツール

利用可能なツールが複数ある場合は、上から順に優先して使う。

### 1. VS Code 統合ブラウザ（推奨）

Playwright ベースの組み込みツール群。追加設定不要で利用可能。
詳細は [references/vscode-browser.md](./references/vscode-browser.md) を参照。

| ツール | 用途 |
|--------|------|
| `open_browser_page` | 新しいページを開く |
| `navigate_page` | URL 遷移・戻る・進む・リロード |
| `read_page` | DOM スナップショット取得（情報抽出に最適） |
| `screenshot_page` | スクリーンショット取得（視覚記録用） |
| `click_element` | 要素クリック（ナビゲーション・タブ切替） |
| `type_in_page` | テキスト入力・キー操作（検索・フィルタ） |
| `hover_element` | ホバー（ツールチップ表示等） |
| `run_playwright_code` | カスタム Playwright コード（スクロール等） |

### 2. フォールバック

上述のツールが利用できない場合、エージェント環境に応じたブラウザ操作ツールを使用する（使用できるツールがない場合もあり得る）。

## Procedure

### Step 1: 対象ページの特定

ユーザーの要求から遷移先を決定する。特定サービスの URL パターンやページ構造はドメイン別スキル（例: `ghe-webui`）を参照。
URL が不明な場合はユーザーに確認する。

### Step 2: ページを開く

ブラウザツールでページを開く。既に同じホストのページが開いている場合はページ内遷移を優先する。

### Step 3: ページ内容の読み取り

ページの DOM スナップショットを取得し、必要な情報を抽出する。
ツール固有の操作方法は [references/](./references/) 配下のツールガイドを参照。

#### 読み取りの一般原則

- DOM スナップショットはスクリーンショットより情報量が多い。情報抽出には DOM スナップショットを優先する
- ページが長い場合はスクロールしてから再読み取りする
- タブやセクションの切り替えが必要な場合は対象タブをクリックしてから DOM を再取得する
- 検索・フィルタが必要な場合は検索ボックスにテキストを入力する

#### 非同期ロードへの対処

モダンな Web UI は一部のデータを非同期でロードする。DOM スナップショットで「Loading」等と表示されている場合は、少し待ってから再度取得する。

### Step 4: 情報の整理と報告

読み取った情報をユーザーの要求に合わせて整理し、報告する:

- テーブル形式のデータは Markdown テーブルに変換
- 設定値は箇条書きで整理
- 必要に応じてスクリーンショットを添付

## 共通操作パターン

### サイドナビゲーション

左サイドバーにサブメニューがある場合:

1. DOM スナップショットでサイドナビの項目一覧を確認
2. 対象のサイドナビ項目をクリック
3. 切り替え後の内容を再取得

### ページネーション

一覧ページがページネーションされている場合:

1. 現在ページの内容を取得
2. 「Next」リンクがあればクリック
3. 繰り返し

### タブ切り替え

Settings ページなどタブで分かれている場合:

1. タブ一覧を確認
2. 対象タブをクリック
3. 切り替え後の内容を取得

### 検索・フィルタ

メンバーやリポジトリの検索:

1. 検索ボックスをフォーカス
2. 検索キーワードを入力
3. Enter キーを送信（必要に応じて）
4. 結果を取得

### 折りたたみ・展開

詳細情報が折りたたまれている場合:

1. 展開トグルをクリック
2. 展開後の内容を取得
