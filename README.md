# github-enterprise-ops-plugin

GitHub Enterprise の管理・運用に関する知識とスキルを提供する VS Code Agent Plugin。

## Install

```
Chat: Install Plugin From Source
```

で `https://github.com/openjny/github-enterprise-ops-plugin` を入力。

または `settings.json` に直接追加:

```json
"chat.pluginLocations": {
    "openjny/github-enterprise-ops-plugin": true
}
```

## Structure

```
.claude-plugin/
  plugin.json         # Plugin metadata
skills/               # Skills (追加予定)
```
